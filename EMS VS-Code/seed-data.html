EMS — Seed Sample Data

Populates every Firestore collection this app reads with realistic volume — enough records that every status/category/tab filter on every page has visible results, not just the dashboard KPIs.

Run this ONCE via Live Server (not by double-clicking the file). Running it more than once will create duplicate records and duplicate Firebase Auth accounts (which will fail harmlessly and be skipped). This does a LOT of sequential writes (300+), so it will take a couple of minutes — watch the log. Delete this file when you're done seeding.
